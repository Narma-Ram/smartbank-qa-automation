# SmartBank Financial BI & Reporting Dashboard

**Project Type:** Financial Analytics, Business Intelligence & QA Automation  
**Status:** In Progress  
**Approach:** Agile Sprint-Based Development  
**Test Automation:** Python, Playwright, pytest  
**Data Validation:** SQL, Pandas, API and Database Reconciliation

## 1. Project Overview

This portfolio project demonstrates how financial reporting dashboards can be developed and validated using a structured, quality-driven approach.

The project combines synthetic banking data, financial KPI calculations, SQL validation, dashboard testing, and automated quality checks to demonstrate end-to-end QA and analytics engineering skills.

## 2. Project Objectives

- Define measurable financial KPIs and business rules.
- Generate and validate synthetic banking data.
- Verify financial calculations and reporting periods.
- Design and test an interactive financial dashboard.
- Reconcile database, API, and dashboard results.
- Automate UI and data validation using Python and Playwright.
- Integrate automated tests into CI/CD pipelines.
- Explore Docker and Kubernetes deployment concepts.

## 4. Quality Engineering Approach

Each sprint follows a repeatable workflow:

1. Define requirements and acceptance criteria.
2. Identify business rules and risks.
3. Design test scenarios and expected results.
4. Implement the feature or validation logic.
5. Execute tests and investigate failures.
6. Document results and commit completed work to GitHub.
